# Финален проект за курса "Програмиране с Python" 2025/2026
## Платформа за частни уроци

Уеб приложение, създадено с FastAPI, което свързва учители и ученици. Проектът включва пълна функционалност за резервации, известия и управление на профили.

## 🚀 Инструкции за инсталиране

1. **Клонирайте проекта:**
   ```bash
   git clone <https://github.com/IvetoY/Python-project/tree/main>

2. **Създайте виртуална среда и я активирайте:**
    ```bash
    python -m venv venv
    # За Windows:
    venv\Scripts\activate
    # За macOS/Linux:
    source venv/bin/activate

2. **Инсталирайте необходимите библиотеки:**

    ```bash
    pip install -r requirements.txt

3. **Стартирайте сървъра:**

    ```bash
    python -m uvicorn app.main:app --reload
    ##Забележка: Отворете апликацията на https:http://127.0.0.1:8000

**Технологии**
Backend: FastAPI, SQLAlchemy (ORM)

Database: SQLite

Frontend: Jinja2 Templates, Bootstrap 5, JavaScript

Validation: Pydantic

**Основни функционалности**
🔍 Търсене: Филтриране на уроци по предмет, град и категория.

📅 Резервации: Клиентите запазват часове, а учителите ги потвърждават или отказват.

🔔 Известия: Системни съобщения за всяко действие (записване, отмяна, плащане).

💳 Плащания: Симулация на плащане и архив на трансакциите (видима за администратор).

🛡️ Админ панел: Верификация на учители, контрол на достъпа и управление на обяви.
